How to publish your changes

  1. Tap ⬇ Download. A zip with the updated config.js and data.js is saved to your phone.
  2. Open the zip in the Files app and tap Extract.
  3. In Chrome (Desktop site on), open the website's GitHub repository and sign in.
  4. Tap Add file → Upload files, select the extracted files, then Commit changes.
  5. The website updates in 1–2 minutes.

Changes are kept as a draft on this phone until you download or discard them. Nothing on this page publishes by itself; only someone signed in to the GitHub account can update the website.
